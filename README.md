# project-assets

個人專案的圖片空間，用於 Steam 工作坊說明頁等外部頁面引用。只放圖片，不含任何原始碼。
Personal image hosting for project pages (e.g. Steam Workshop descriptions). Images only, no source code.

## 結構 Structure

```
<category>/<project>/<usage>/...
rimworld/MechanoidGravshipSwarmProtocol/workshop/
  banner/   section banners (_en / _zh)
  ig/       infographics (_en / _zh)
  preview/  workshop preview thumbnail
```

資料夾與檔名不使用空格。Folder and file names contain no spaces.
